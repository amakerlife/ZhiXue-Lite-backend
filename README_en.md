A lightweight web appbackend that integrates with the official ZhiXue API.

---

## Quick Start

```bash
git clone https://github.com/amakerlife/ZhiXue-Lite-backend
cd ZhiXue-Lite-backend
mv ./example.env ./.env
vim ./.env
pip install .
flask run
```

## Notes

Before using this project, make sure you have a teacher account for the target school with permission to view at least school-level reports. For full functionality, add a principal or administrator account. This project does not provide a captcha API; please handle captcha solving yourself.
